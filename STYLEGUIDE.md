# Project Style Guide

## Naming
- **Namespaces:** lowercase, apart from acronyms
- **Classes/Structs/Types:** PascalCase
- **Local variables:** snake_case
- **Compile time constants:** ALL_CAPS_UNITS
- **Free Functions/Class methods:** camelCase
- **Private member variables:** suffix_
- **Files:** match class name with case, snake_case for utilities
